# 1.0.46 更新ログ

## 目的

1. **クエストモードの「SAVE / LOAD」「CLEAR REWARD」「KEY BINDINGS」モーダルを、
   SKILL TREE / EQUIP SKILLS と同一のUI（クエストモーダルスタイル）に統一する**
2. **クエストモード系モーダル7画面のタイトル文字サイズを揃える**
   （DIFFICULTY / SKILL TREE / EQUIP SKILLS / UPGRADE / SAVE・LOAD / KEY BINDINGS / CLEAR REWARD）

---

## 変更前の状態

| 画面 | 実装 | 枠・タイトル |
|---|---|---|
| DIFFICULTY / SKILL TREE / STAR UPGRADE | `js/questMapUI.js` の `openQuestMenuModal()` が生成 | `.quest-modal` / `.quest-modal-box` / `.quest-modal-title`（**26px**） |
| EQUIP SKILLS | 同上 | 同上だが `.quest-modal-skill .quest-modal-title` で **22px に上書き** |
| SAVE / LOAD | `index.html` の静的HTML | `.save-modal` / `.save-modal-content` / `<h2>`（ブラウザ既定 ≈24px・太字・グレーのグラデ枠） |
| CLEAR REWARD | 同上 | 同上 |
| KEY BINDINGS | 同上 | 同上。内容は設定画面と共用の `.keybind-row`（横並び） |

→ 見た目が2系統に分かれ、タイトルサイズも 26 / 22 / 24px と不揃いだった。

---

## 変更内容

### 1. `index.html` — 3モーダルをクエストモーダル構造へ（ID は全維持）

```html
<div id="saveModal" class="quest-modal hidden">
  <div id="questSaveMenu" class="quest-modal-box quest-modal-save">
    <button id="saveToQuestMenuBackBtn" class="quest-modal-close-btn" title="閉じる">×</button>
    <div class="quest-modal-title">SAVE / LOAD</div>
    <div class="quest-modal-content">
      <div id="questSlots" class="quest-slot-list"></div>
    </div>
  </div>
</div>
```

- CLEAR REWARD は `quest-modal-reward` ＋ `#clearRewardContent.quest-reward-panel`
- KEY BINDINGS は `quest-modal-keybind` ＋ `#keybindConfigContent.keybind-modal-list` ＋
  `.quest-modal-actions` 内に `class="quest-modal-btn"` の Save ボタン
- `#keybindConfigContent` のクラスを **`.keybind-row` → `.keybind-modal-list`** に変更
  （`.keybind-row` は設定画面 `#settings` の KEY セクションと共用のため切り離した）
- MUSIC モーダルは対象外のため `.save-modal` のまま（`.save-modal` 系CSSも温存）

### 2. `style.css`

- `:root` に `--quest-modal-title-size: 26px` を新設し、`.quest-modal-title` はこの変数のみでサイズ決定
- `.quest-modal-box.quest-modal-skill .quest-modal-title` の `font-size: 22px` を削除（`margin-bottom: 8px` は維持）
- `.quest-modal.hidden { display: none; }` を追加
  （`.quest-modal` は `display: flex` のため、`.hidden` 単体では閉じられない）
- 画面階層セクションに `#saveModal, #clearRewardModal, #keybindConfigModal { z-index: 10010; }` を追加し、
  旧 `.save-modal` と同じ重なり順を維持
- 新セクション「SAVE/LOAD・CLEAR REWARD・KEY BIND モーダル」を追加
  - 幅：3画面共通 `min(640px, calc(var(--dvw) * 92))`、`padding: 18px 20px`
  - box を `flex-direction: column`、`.quest-modal-content` を `flex:1 + overflow-y:auto`（見切れ防止）
  - `.quest-reward-panel`（報酬本文のカード）、`.quest-modal-actions`（保存ボタン中央寄せ）
- SAVE/LOAD スロットをカードトーンへ変更（`.quest-slot-card` / `.slot-*` / `.slot-actions button` / `.slot-empty`）
- キーバインド項目を行型カードへ変更（`.keybind-modal-list` / `.keybind-modal-item` / `.keybind-modal-label` /
  `.keybind-modal-controls select` / `#keybindConfigSaveBtn`）

### 3. JS は無変更

`js/main.js` / `js/questResult.js` は ID 参照と `hidden` クラスの add/remove のみで開閉するため、
構造変更後もそのまま動作する（`handleQuestSaveClearModalKey()` の `getComputedStyle(el).display !== "none"` 判定も
`.quest-modal.hidden { display:none }` によって従来どおり成立）。

### 4. バージョン

- `js/version.js` → `1.0.46`
- `service-worker.js` の `CACHE_NAME` → `mametype-v1.0.46`

## 動作仕様（変更後）

| 項目 | 動作 |
|---|---|
| SAVE / LOAD | クエストモーダルと同じ上寄せ・暗色枠（640px）。3スロットは縦積みカード。LOAD/SAVE はクエストモーダルのボタンと同トーン |
| CLEAR REWARD | 報酬本文がカード内に表示（EXTRA 併記時の `<hr>` もJS側のままで維持） |
| KEY BINDINGS | 4項目（Unlock / Auto Lock / Pause / Active Skill）が「ラベル左・セレクト右」の行型カード。下部に Save Keybinds ボタン |
| 閉じる操作 | ×ボタン / `b` / `Esc`（キーバインドは `Enter` も）は従来どおり。`hidden` クラスでの開閉も従来どおり |
| タイトルサイズ | 7画面すべて `--quest-modal-title-size`（26px）で統一 |
| 重なり順 | 3モーダルは `z-index: 10010`（旧 `.save-modal` と同一）。プレイヤーHUD（10500）等の上位要素との関係も不変 |

## 副作用の確認

- タイトルは `<h2>`（太字）から `.quest-modal-title`（非太字）に変わるため、SAVE/LOAD・CLEAR REWARD・KEY BINDINGS の
  タイトルは「太字が外れて 26px」になる。DIFFICULTY / SKILL TREE と同一仕様。
  ※全画面を太字にしたい場合は `--quest-modal-title-size` と合わせて `.quest-modal-title { font-weight: 700 }` を追加すればよい。
- 3モーダルは中央寄せから上寄せ（`.quest-modal` の `padding-top: 20px` / `align-items: flex-start`）になり、
  SKILL TREE / EQUIP SKILLS と同じ表示位置になる。
- JS は変更していないため、セーブ完了イベント（`questSlotSaved`）→ クリア報酬ポップアップの流れも不変。
