## v1.0.32 完了 — 適用登録の陳腐化防止・INP緩和

### 症状と原因
- 「適用しています...」がCmd+Rまでそのまま: 適用ボタンのハンドラが古い `registration` を掴み続け、`waiting=null` のままになる（陳腐化）
- Windows ChromeでINP約2秒: 打鍵ハンドラ内でタイプ音のWebAudioグラフを同期生成し、入力→描画のクリティカルパスを塞いでいた

### 修正内容
1. **`js/main.js`** — 適用開始時に `getRegistration()` で取り直し、`SKIP_WAITING` 再送時も登録を更新
2. **`js/inputCore.js`** — タイプ音を後追い再生に変更（入力判定・描画を先に通す）
3. **`style.css`** — Windowsタイピング表示の `text-shadow` を撤去（ペイント微減）
4. **`js/version.js`** → `1.0.32`
5. **`service-worker.js`** — `CACHE_NAME` を `mametype-v1.0.32` に更新
6. **`CHANGELOG.md`** / `Log details/1.0.32.md` を更新

### 副作用の確認
- renderer不変。タイピング表示の更新経路は不変
- タイプ音の音質・音量は不変（再生タイミングのみ最大50ms後追い）
- Macの体感は不変、WindowsのINPのみ改善方向

### 確認手順
1. 「今すぐ更新」→バーが自動で100%まで進み自動で再起動するか確認
2. Windows ChromeのDevTools→Performance→Interactionsで打鍵のINPが短縮したか確認
3. タイプ音が鳴るか、入力表示が遅れていないか確認
