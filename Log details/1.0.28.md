## v1.0.28 完了 — Safari進捗・ボタン中央・Windows文字・黒画面対策

### 症状と原因
- Safariでアップデート進捗モーダルが自動で増えず、Cmd+Rで増える
  - 自動 `registration.update()` 廃止（v1.0.25）＋SafariのSWキャッシュ保持で install 自体が始まらない
  - `start` 受信時にモーダル側が0%のまま、完了名 `complete-boot` vs `complete` の不一致
- 「今すぐ更新」の文字が偏る: `display:inline-flex` に対して `text-align` のみで中央化されない
- WindowsのUI全体の文字がにじむ: 丸ゴ自ホストのヒンティング弱＋ClearType/スケーリング/ステージtransform
- Windowsでhardresetしないと真っ黒: 古いSW＋古いHTTPキャッシュのまま更新契機がなく、コア読み込み停滞で止まる

### 修正内容
1. **`js/main.js`**
   - 手動チェック押下直後に `showUpdateProgressPreparing()` を先行表示
   - `handleUpdateProgress` の `start` 時にモーダル側も0%更新、`complete-boot` を受理
   - 起動時に `version.js` を `no-store` で1回取得し差分があれば更新誘導（案A、自動DLなし）
   - `loadCoreAssets` に30秒タイムアウト＋継続フォールバック（真っ黒防止）
   - DOMContentLoadedでWindows判定し `body.win` を付与
2. **`style.css`**
   - `.update-button` に `display:inline-flex; justify-content:center; align-items:center` を追加
   - `body.win` 向けの静的CSS補正（UI全体 0.1px、タイピング表示 0.15px＋weight 500）
3. **`js/version.js`** → `1.0.28`
4. **`service-worker.js`** — `CACHE_NAME` を `mametype-v1.0.28` に更新
5. **`CHANGELOG.md`** / `Log details/1.0.28.md` を更新

### 副作用の確認
- renderer（`renderer.js`/`defenseRenderer.js`）は不変。タイピング表示遅延なし
- Windows補正は静的CSSのみ。500は実ウェイト同梱済みで疑似ボールドなし
- 起動時バージョンチェックは軽量fetch1回のみ。描画ループに介入しない
