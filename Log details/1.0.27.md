## v1.0.27 完了 — ゲーム開始直後の別問題チラ見え修正（Windows）

### 症状と原因
- スタンダード等をスタートした時、最初に別の問題が一瞬表示される（Windows のみ）
- `font-display: swap` により、フォント取得完了前にフォールバックで描画 → 後から正しいフォントに差し替わる
- この切替えの隙間に前回問題のフォントキャッシュや表示バッファが残って見える
- Mac は swap が速く目立たないため発生しない

### 修正内容
1. **`js/gameCore.js`** — `loadText()` で `renderState()` の前に `document.fonts.ready` を待機
   - フォント切替完了後に描画するため、チラ見えを防止
   - タイピング中は影響なし（初回描画時のみ数ms〜数十ms待機）
2. **`js/version.js`** → `1.0.27`
3. **`service-worker.js`** — `CACHE_NAME` を `mametype-v1.0.27` に更新
4. **`CHANGELOG.md`** / `Log details/1.0.27.md` を更新

### 副作用の確認
- タイピング遅延には繋がらない（待機は初回描画の1回のみ）
- 2問目以降はフォントがメモリ常駐のため待機不要
- フォントは起動時に全サブセット先読み済みのため、待機は通常数ms〜数十ms

### 確認手順
1. Windows でスタンダード/タイムアタック/長文を開始
2. 最初の問題が正しく表示され、別問題がチラ見えしないことを確認
3. タイピング中の表示遅延がないことを確認
