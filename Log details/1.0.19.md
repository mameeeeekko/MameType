## v1.0.19 完了 — 起動不能とタイピング遅延の根本修正

### 症状の原因分析（2つとも判明）

**① 起動不能 `failed to fetch at service-worker.js:615:16`**

旧 fetch ハンドラは**全リクエストで真っ先に `caches.match()`（キャッシュ読み取り）**を行い、ネットワーク失敗時は `throw error` で**エラーをページに連鎖**させていました。CacheStorage はオリジン単位の**排他ロック**のため、
- install が大量の `cache.put` を連続実行 → ページのリクエストがロック待ちで詰まる
- fetch がタイムアウト/失敗 → throw → ページが読み込めず「ハードリセットしないと起動しない」

**② タイピング遅延**

タイピング音や音源の `fetch` も SW に横取りされ、**その度にキャッシュロック待ち**が発生（特に音声書き込み直後は数十〜数百msの遅延）。打鍵ごとに遅延が積み上がっていました。

### 修正内容

**1. fetch ハンドラを「ネットワーク最優先」に刷新**（615行の `throw` を撤去）
```
オンライン : 即ネットワーク応答（キャッシュ読み取りを挟まない → 遅延ゼロ）
書き込み   : fire-and-forget（応答を待たせない）
ネット失敗 : その時だけキャッシュへフォールバック
キャッシュ無 : オフライン用 503 を返す（throw しない）
```

**2. install は「起動コア20件」だけに縮小** → 約1秒で有効化。一括キャッシュの長時間ロックを廃止

**3. 残りは activate 後バックグラウンドで「1件ずつ・300ms間隔」**でキャッシュ
- 進捗は中央下バー、完了で「オフラインでも遊べるようになりました 🎮」

**4. キャッシュバージョン v1.0.19 に更新**（壊れたキャッシュを確実に置換）
