## 実装完了サマリー

### 変更内容（4ファイル）

**1. `js/stageScale.js` — デバイスピクセルスナップ（原因1対策・効果大）**
- `fitStage()` がレターボックス原点（`--stage-ox` / `--stage-oy`）を**デバイスピクセル整数に丸める**ように変更。以前は `translate(-50%,-50%)` 中央寄せで原点が 0.5px などの端数に落ち、ステージ全体がバイリニア再サンプリングされて「滲んで」いました
- ステージ表示幅もデバイスpx整数になるよう scale をスナップ（`floor` で横スクロールバーを防止）→ Canvas のバッキングストアと画面ピクセルが 1:1 に対応
- `clientToStage()` を丸めた原点と同期（questMap のツールチップ等のクリック座標がずれない）

**2. `style.css` — body の中央寄せ方式変更**
- `:root` に `--stage-ox: 0px; --stage-oy: 0px;` を追加
- `body` を `left:0; top:0` ＋ `translate(var(--stage-ox), var(--stage-oy)) scale(...)` + `transform-origin: 0 0` に変更（JS が設定した整数デバイスpx原点をそのまま使う）

**3. `js/performance.js` — DPR下限の引き上げ（原因3対策）**
- `low` の dprCap: 1.0 → **1.25**、Auto 自動劣化の最終段階も 1.0 → **1.25**
- Windows 125% 表示（DPR=1.25）で Canvas が 1:1 解像度になり文字が鮮明に。150% 環境でも 1.5→1.25 のわずかな引き伸ばしに軽減。Low は既に影OFF・粒子40%・30fps なので増分コストは軽微

**4. `js/main.js` — フォント読み込み後の再フィット**
- `document.fonts.ready` 後に `fitStage()` ＋ `resize` 発火を1回だけ実行。フォールバック字形で描かれた Canvas の残骸と、スナップ前の解像度のままの Canvas を確実に再フィット

### 期待される効果
- Windows 125%/150% 環境の「画面全体がぼやける・滲む」が大幅に改善（原点端数の解消は全滲みの主因でした）
- Mac / 100%表示環境では原点が整数なので挙動は変わりません（影響ゼロ）

### 確認方法
Windows 実機でページをリロードし、メニュー文字・ゲーム中のタイピング文字が滲まなくなったか確認してください。特に 125% スケーリング環境＋品質「Low」で効果が顕著です。リサイズ・フルスクリーン切替・クリック位置（quest マップのツールチップ）も念のため一度確認を。

### 残課題
- Windows で ClearType（サブピクセルAA）は技術的に使えないため、滲みが完全にゼロにはなりません（今回の対策でかなり緩和されます）
- 対策4「文字だけグロー無効化」は未実装です。引き続き滲みが気になるようなら実装します（Low品質時のみ fillText の shadow を 0 にする方式を想定）
