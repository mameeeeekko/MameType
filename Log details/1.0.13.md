# 1.0.13

## 今回の修正内容（v1.0.13）

「潰れて見える」原因の核心は **Windows のグレースケール AA**（合成レイヤー上では ClearType が使えないため、文字が Mac より痩せて细く見える）です。これを Windows 限定で安価に補正しました。

**1. `js/performance.js` — Canvas の小さい文字を太くするパッチ**
- `fillText` をプロトタイプレベルでラップし、**16px 未満の文字**を描いた直後に**同色の細いストローク**（線幅 = サイズ×0.05、最低0.35）を重ねてわずかに太くする
- 塗り色・グラデーション・影・アルファはそのまま引き継ぐ（線幅/結合スタイルは元に戻す）
- コストは小さい文字1回分の `strokeText` のみ。Mac/Linux では一切動作しない（見た目不変）

**2. `style.css` + `js/main.js` — DOM テキストの太字化**
- Windows 判定時に `body.win-text-thicken` を付与
- `-webkit-text-stroke: 0.2px`（全テキストの縁をわずかに太く）＋ `font-weight: 500`
- M PLUS Rounded 1c の実ウェイト 500 は同梱済みなので疑似ボールドにならず綺麗（Inter は 400 のまま）

**3. バージョン更新（配信対策）**
- `js/version.js` / `service-worker.js` / `CHANGELOG.md` を **v1.0.13** に更新 → 既存 Windows ユーザーにも更新が配信される

## 確認方法
Windows でリロードしてください（SW の「更新準備完了」が出たら適用）。文字が太くなり「痩せ・潰れ」が緩和されているはずです。

## 調整ポイント（強すぎ/弱すぎなら）
- Canvas の太さ：`performance.js` の `Math.max(0.35, size * 0.05)` の係数（例：0.03〜0.08）
- DOM の太さ：`style.css` の `-webkit-text-stroke: 0.2px`（0.15〜0.3px）と `font-weight: 500`
- 対象サイズの閾値：`size < 16`

なお、Windows の ClearType 無効化自体はブラウザ仕様のため完全には消せませんが、これで「痩せて潰れた」印象はかなり改善するはずです。まだ違和感があれば、太さの数値を教えてもらえれば微調整します。
