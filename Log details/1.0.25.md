## v1.0.25 完了 — アップデート確認の手動化と進捗表示改善

### 症状と原因
- ページロード時に自動で `registration.update()` が呼び出され、バックグラウンドで全アセットのダウンロードが走っていた
- 低スペックPC / Windows でこのバックグラウンドDLが負荷となり、ゲームプレイに影響していた
- ユーザーが意図しないタイミングでDLが開始されていた

### 修正内容
1. **`js/main.js`** — 自動更新チェックを除去:
   - ページロード時の `registration.update()` 呼び出しを削除
   - `setInterval` による定期更新チェック（1時間毎）を削除
   - `visibilitychange` によるタブ復帰時の更新チェックを削除
   - 手動「アップデートを確認」ボタンでのみ `registration.update()` を実行
2. **`js/main.js`** — `showUpdateProgressPreparing()` を修正:
   - ダウンロード中にモーダルを表示（以前は非表示にして中央下バーを使っていた）
   - プログレスバー・%・ファイル数をモーダル内に表示
   - ボタンは非表示（ダウンロード完了まで無効）
3. **`js/main.js`** — `handleUpdateProgress()` を修正:
   - 中央下バー（`_updateSwDownloadBar`）の代わりにモーダルの `updateProgressUI()` を使用
4. **`js/main.js`** — `showUpdateReady()` を修正:
   - ダウンロード完了後、100%表示してからボタンを有効化
   - モーダルは表示状態を維持（切り替え不要）
5. **`style.css`** — `.update-button` に `text-align: center` を追加
6. **`service-worker.js`** — `CACHE_NAME` を `mametype-v1.0.25` に更新
7. **`js/version.js`** → `1.0.25`
8. **`CHANGELOG.md`** / `Log details/1.0.25.md` を更新

### 副作用の確認
- バックグラウンドDLがなくなったことで、低スペックPC/Windows の常時負荷が軽減
- ユーザーが「アップデートを確認」を押したときのみDLが開始（タイミングを選択可能）
- DL中はモーダルに進捗が表示されているため、何が起きているか明確
- DLが不要なプレイ中はSW関連のネットワーク通信が発生しない

### 確認手順
1. 設定画面を開く
2. 「アップデートを確認」ボタンを押す
3. 新しいバージョンがある場合：モーダルが表示され、ダウンロード進捗（%・ファイル数）が表示される
4. ダウンロード完了後：「今すぐ更新」ボタンが有効化される
5. 「今すぐ更新」を押すと、100%表示後にリロードされる
6. 新しいバージョンがない場合：「最新です（v1.0.25）」と表示される
