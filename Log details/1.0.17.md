## 実装完了（v1.0.17）サマリー

### 1. 最重要：service-worker.js の構文エラーを修正

作業ツリーの service-worker.js の **CORE_ASSETS 配列の中**（`select.mp3` と `questmenu.mp3` の間）に、以前の作業途中で割り込んだ `await new Promise(...)` が残っていました。これは配列リテラル内の不正コードで、**SW 全体がパース不能 → 登録失敗**になる致命的なエラーです。
- この2行を除去し、配列を正常に戻しました（`が確認でき次第、SW が正しく install されるようになります）
- これにより「裏でキャッシュされているのに重い」「通知が出ない」の原因のひとつが解消します

### 2. 中央下のダウンロードバー（新規）

`index.html` に SW 用の進捗バー `#swDownloadIndicator` を追加しました。既存の「アセット読み込み中…」のバーと同じデザイン・位置（中央下・pointer-events:none・ゲーム操作を邪魔しない）で、`remaining-load-indicator` のスタイルを共有します。

**表示の流れ:**
| 状況 | 表示 |
|------|------|
| 初回アクセスでオフライン用データ取得中 | 中央下: `オフラインデータをダウンロード中 NN%` |
| アップデートデータ取得中 | 中央下: `アップデートデータをダウンロード中 NN%` |
| 一部ファイル失敗 | `… NN% （一部スキップ）` |
| 完了（初回） | バーが消え → **「オフラインでも遊べるようになりました 🎮」** のモーダル |
| 完了（更新） | バーが消え → **「新しいバージョンの準備が完了しました」** ＋ 今すぐ更新/後で |

### 3. アップデート通知モーダルからバーを撤去

ご指摘どおり「通知が出る頃には常に100%」なので、
- ダウンロード中は**モーダルを出さず**（バーで進捗）、
- `showUpdateReady` / `showOfflineReady` / `showUpdateNotification` では**モーダル側のプログレスバーを常に非表示**にしました。お知らせは文字だけのスッキリした表示になります。
